About Me

Hello! I’m Jhon Philip Villegas, an aspiring Front-End Developer passionate about creating modern, responsive, and user-friendly websites. I enjoy transforming my ideas into functional and visually appealing web experiences using HTML, CSS, JavaScript, and other web technologies.

I am currently a student at St. Dominic College of Asia continuously improving my programming and design skills through hands-on projects and self-learning. I enjoy exploring UI/UX design, responsive layouts, and interactive web elements that improve user experience.

My technical skills include HTML, CSS, JavaScript, Java, C, MySQL, Git, GitHub, and Visual Studio Code. I also enjoy learning new technologies and adapting to modern development practices to expand my knowledge in software and web development.

Beyond coding, I value creativity, problem-solving, teamwork, and continuous learning. My goal is to become a professional software developer capable of building impactful applications and contributing to meaningful real-world projects in the future.
